## Overview

This repository contains all student notebooks for camp week. The camp is a five day introduction to Python programming and machine learning, built around interactive marimo notebooks that run entirely in the browser through molab. No installations, no setup, no excuses: click a link and start coding.

Each day includes two notebooks:

- **Exercises**: the core material for the day, worked through together and independently
- **Challenges**: a bonus pack of game style problems for early finishers, worth points on the camp leaderboard

## Getting started

1. Click the molab link for today in the schedule below
2. The notebook opens in your browser and is ready to run
3. Execute a cell with **Ctrl+Enter** (Windows) or **Cmd+Enter** (Mac)
4. Every exercise includes a built in hint: read the hint before raising your hand

## The leaderboard

Challenge problems earn points, tracked daily on the camp leaderboard. Points are awarded for correct solutions, creative approaches, and helping other campers debug. Standings are announced each morning.
