## Overview

This repository contains the exercise notebooks for camp week. The camp is a five day introduction to Python programming, built around interactive marimo notebooks that run entirely in the browser through molab. No installations, no setup: click a link and start coding.

## How camp works

Most of the week runs on **pair programming**. You and a partner share one notebook: one person is the *driver* (typing) and the other is the *navigator* (reading ahead, catching mistakes, asking "wait, why?"). You swap roles after every exercise.

The rhythm each day:

1. A student or pair recaps yesterday
2. You open a fresh, empty molab notebook
3. The instructor explains an exercise on the main screen
4. You and your partner solve it together while the staff circulate
5. Pairs share solutions, and the instructor goes deeper on the concepts you just used
6. Repeat!

The notebooks below hold each day's full exercise list, ordered from foundational to challenging. The early exercises are the core material; the **Level Up** section in each notebook has the bigger builds for when you're ready for more.

## Project day

Friday is yours. Build something original using anything from the week: a text generator, a word similarity game, an interactive tool. The showcase closes out camp, and every project presents for about two minutes.
